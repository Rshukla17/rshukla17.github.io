# Rajan Shukla — Personal Portfolio

Single-page portfolio: `index.html`, `styles.css`, `script.js`.

## Deploy (GitHub Pages)
Replace the files in the `rshukla17.github.io` repo with these three files
(plus this README and `.nojekyll`), commit, and push. The site updates in a
minute or two.

## Changing the photo
The hero currently uses the GitHub avatar. To use a different picture:
1. Add the image file to the repo root (e.g. `photo.jpg`).
2. In `index.html`, find the `<img>` inside `<figure class="portrait">` and
   change `src` to `photo.jpg`.
A square image (at least 600×600) crops best into the circle.
